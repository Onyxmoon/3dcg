## Task
[PDF document](Meilenstein-2/Arbeitsblatt2.pdf) for task sheet 2.

**Summary of the task to be processed for the Processing-Sketch**

> Now you should look for ways to bring dynamic elements into your digital image composition from task sheet 1 without violating the design rules. So task sheets 1 and 2 are steps that build on each other.
> The task deliberately leaves a lot of freedom of interpretation, because we always look forward to creative solutions ;)
>
> **Task 1**
> Use random elements for moments of tension within the composition. Modifies all elements of the picture composition (color selection, formal language and design grid) in order to test hypotheses about the underlying design rules by comparing the work template and the free interpretation.
> The Processing Sketch is intended to provide new variations of the selected work template with each call. The individual elements of the composition are to be defined in the model space and then positioned by transformations (translate(), rotate(), scale() etc.).
>
> **Task 2**
> Slowly change individual parameters of the image composition within the runtime of the sketch and thus create an animated variation of the work template. At least one animation must be created by changing the transformation parameters and not through changes to the model.
>
> **Task 3**
> Allows the viewer to change and/or intervene in the image composition via mouse and keyboard, thus creating an interactive variation of the work template. Again, at least one change must be made by changing the transformation parameters.
